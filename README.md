# Travel Notes

A simple travel website created for Assignment 2. The project uses Flexbox and CSS Grid to arrange navigation, cards, a gallery and a portfolio page.

## Technologies

- HTML
- CSS
- Flexbox
- CSS Grid

No JavaScript or external frameworks are used.

## Pages

| File | Description |
| --- | --- |
| index.html | Home page with Flexbox navigation |
| cards.html | Three equal-height travel cards with photos and links |
| layout.html | Page layout with a header, left sidebar, main content and footer using grid areas |
| gallery.html | Nine-image grid with captions that appear on hover |
| portfolio.html | Project portfolio combining Grid and Flexbox |

All pages share style.css. The layout adapts to smaller screens using media queries. Gallery captions are also available through keyboard focus and remain visible on touch devices.

## Running Locally

1. Clone or download this repository.
2. Open index.html in a browser.

No installation or local server is required. Use the navigation bar to move between pages.

## Images

Photos are loaded from [Lorem Picsum](https://picsum.photos/) using fixed image IDs. An internet connection is required to display them.
